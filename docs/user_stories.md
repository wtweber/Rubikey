## User stories

Describe user-visible behavior of the app in a simple format, such as: "as a <role> I want to <action> so that I can <goal>"
Include acceptance criteria
Be small enough to complete during the project
Cover both essential and optional features
Be stored in docs/user_stories.md

Expected Quantity
* 5-10 user stories total
* At least 3 essential stories
* At least 1 sad-path/error-handling story

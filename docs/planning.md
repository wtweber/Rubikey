## Planning

## App Name
* Rubikey - Terminal Application Password Manager

## Core features
* Store Password
* Retrieve password
* Generate password
* Search for passwords
* Set master password
* Change master password

## Optional features
* Create Folders
* Organize Folders
* Custom special characters
* Custom number of uppercase / lowercase / special characters
* Forced capitalization of letters / numbers (password requirement stuff)
* Time out of the application if user makes no input for x amount of time

## Collaboration
* Daily updates to eachother for the work / progress we are doing
* We'll dedicate time to do pair programming when our schedules align
* We will discuss plans for code structure before we work on it individually

## Completion
* Core features are implemented
* Test suite that verifies the core features / stretch features if they are present
* At least 80% statement coverage for test suite (we can use a coverage tool for Ruby for this part)
* Documentation for the README.md so the project can be run on the graders end, documentation for the design / backlog / everything in the docs folder.

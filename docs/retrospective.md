## Mid-Project Retrospective

### What Went Well
* Pair Programming (We used Zoom screenshare, went great)
* Project Proposal went smoothly
* The planning phase went well, we have not needed to make drastic changes to our plans

### What Was Difficult
* We kept having difficulties meeting with all of Rubocop's stylistic enforcing
* RSpec tests we sometimes make after the function instead of before to test its functionality

### To Improve For Next Time
* Use branches for more complicated features (especially as we move into using the database)
* Run Rubocop more often while implementing changes to catch formatting errors earlier and not all at once
* We need to use the Github issues page for when we add features / develop for the user stories (We've been using the user_stories.md file)
* Remembering to create RSpec tests prior to writing the functionality
* Add documentation to major methods / classes
